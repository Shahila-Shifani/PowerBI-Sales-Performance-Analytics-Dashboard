# Beginner guide

## What is Power BI?
Power BI is a Microsoft tool for turning data into interactive reports.

## Importing and Power Query
Use Get Data to connect to Excel. Power Query is the data preparation area: it lets you change types, remove empty rows, trim text and apply repeatable cleaning steps.

## DAX and measures
DAX is the formula language used in Power BI. A measure is calculated when the report is queried and usually responds to filters. For example, `SUM(Orders[Sales])` adds the Sales column for the currently selected rows.

## Visuals and slicers
A chart displays a field against a measure. A slicer is a visual filter that lets a report reader choose dates, regions or categories.

## Interpreting insights
Look for trends, differences and outliers. High sales do not always mean high profit. Check profit and margin before calling a product successful.
