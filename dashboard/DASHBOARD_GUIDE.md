# One-page dashboard layout

## Top row
Add five Card visuals:
- `[Total Sales]`
- `[Total Profit]`
- `[Total Orders]`
- `[Average Order Value]`
- `[Profit Margin]` (format as percentage)

## Middle row
- Line chart: Order Date (month) on X-axis and Total Sales on Y-axis.
- Line chart: Order Date (month) on X-axis and Total Profit on Y-axis.
- Bar chart: Region on Y-axis and Total Sales on X-axis.

## Bottom row
- Bar or column chart: Category and Total Sales.
- Bar chart: Product Name and Total Sales; apply a Top N filter (for example, top 10).
- Optional matrix: Category, Sub-Category, Total Sales and Total Profit.

## Slicers
Add Order Date, Region and Category slicers. Confirm each slicer filters the charts.

Use readable titles, consistent number formats and restrained colours. Avoid treating this guide as a screenshot of a completed report.
